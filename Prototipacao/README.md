# TaskFlow – Protótipo de alta fidelidade

Protótipo navegável desenvolvido em HTML, CSS e JavaScript para a atividade de criação de protótipos.

## Como executar
1. Extraia o arquivo ZIP.
2. Abra a pasta `taskflow-prototipo`.
3. Dê dois cliques em `index.html` para abrir no navegador.

Não precisa instalar nada nem configurar banco de dados.

## Funcionalidades demonstradas
- HU01: cadastro de usuário (simulado).
- HU02: login (simulado).
- HU03: cadastro de tarefas.
- HU04: edição de tarefas.
- HU09: consulta, busca e filtro de tarefas.

## Observação
Este é um protótipo acadêmico com dados fictícios. As informações ficam apenas na memória da página e são reiniciadas ao atualizar o navegador. Não representa o sistema final conectado a banco de dados.
