
# Requisitos de Usuário – TaskFlow

## Introdução

O TaskFlow é um sistema de gerenciamento de tarefas que permite aos usuários organizar suas atividades, acompanhar prazos e controlar o andamento de suas tarefas.

## Requisitos Funcionais

### RF01 – Cadastro de usuários
O sistema deverá permitir que novos usuários realizem seu cadastro.

### RF02 – Login
O sistema deverá permitir que os usuários acessem suas contas.

### RF03 – Cadastrar tarefas
O sistema deverá permitir que o usuário cadastre novas tarefas.

### RF04 – Editar tarefas
O sistema deverá permitir que o usuário edite tarefas existentes.

### RF05 – Excluir tarefas
O sistema deverá permitir que o usuário exclua tarefas.

### RF06 – Definir prioridades
O sistema deverá permitir classificar tarefas como Alta, Média ou Baixa.

### RF07 – Definir prazos
O sistema deverá permitir definir datas de vencimento para as tarefas.

### RF08 – Atualizar status
O sistema deverá permitir alterar o status das tarefas para A fazer, Em andamento ou Concluída.

### RF09 – Consultar tarefas
O sistema deverá permitir visualizar as tarefas cadastradas.

### RF10 – Pesquisar tarefas
O sistema deverá permitir pesquisar e filtrar tarefas.

## Considerações finais

Os requisitos apresentados definem as principais funcionalidades que o TaskFlow deverá oferecer aos seus usuários.
