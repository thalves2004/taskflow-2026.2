# Requisitos Funcionais – TaskFlow

## Introdução

Este documento apresenta os requisitos funcionais do sistema TaskFlow, descrevendo as funcionalidades que o sistema deverá oferecer aos usuários.

## Requisitos

### RF01 – Cadastro de usuários
- **Descrição:** O sistema deverá permitir que novos usuários realizem seu cadastro.
- **Prioridade:** Alta

### RF02 – Login
- **Descrição:** O sistema deverá permitir que os usuários acessem suas contas.
- **Prioridade:** Alta

### RF03 – Cadastrar tarefas
- **Descrição:** O sistema deverá permitir que o usuário cadastre novas tarefas.
- **Prioridade:** Alta

### RF04 – Editar tarefas
- **Descrição:** O sistema deverá permitir que o usuário edite tarefas existentes.
- **Prioridade:** Alta

### RF05 – Excluir tarefas
- **Descrição:** O sistema deverá permitir que o usuário exclua tarefas.
- **Prioridade:** Média

### RF06 – Definir prioridades
- **Descrição:** O sistema deverá permitir classificar tarefas como Alta, Média ou Baixa.
- **Prioridade:** Alta

### RF07 – Definir prazos
- **Descrição:** O sistema deverá permitir definir datas de vencimento para as tarefas.
- **Prioridade:** Alta

### RF08 – Atualizar status
- **Descrição:** O sistema deverá permitir alterar o status das tarefas para A fazer, Em andamento ou Concluída.
- **Prioridade:** Alta

### RF09 – Consultar tarefas
- **Descrição:** O sistema deverá permitir visualizar as tarefas cadastradas.
- **Prioridade:** Alta

### RF10 – Pesquisar tarefas
- **Descrição:** O sistema deverá permitir pesquisar e filtrar tarefas.
- **Prioridade:** Média

## Considerações finais

Os requisitos apresentados descrevem as principais funcionalidades esperadas do TaskFlow.
